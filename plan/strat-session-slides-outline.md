- Доступные среды: WinSurf (dev), VoiceBot (интервью)
- Оба не подходят для итерационной работы
- MCP в ChatGPT без PRO — ограничения и обходные пути

## Слайд 9 — Разрозненность компонентов
- Интеграционных швов не хватает
- VoiceBot не дергает MCP и не триггерит конвейеры
- Есть один сильно интегрированный контур — туда пытаемся «впихивать» новое

## Слайд 10 — Требования к VoiceBot
- Дорабатываемый API «по требованию» (пример: создание тасков)
- Клиенты и расширения: WebRTC-клиент, кастомизация, страницы расширения
- Альтернатива: пушить OpenCanvas (медленно)

## Слайд 11 — Срез статуса (сегодня)
- Инструменты/подходы/библиотеки выбраны; есть адаптеры
- Слабые места: Telegram-интеграции; нет playground для исполнителей
- Новое: AgentFab «проснулся»; первый эксперимент PresentationMaker

## Слайд 12 — Исходные принципы
- AI — окно возможностей: не наблюдать, а возглавлять
- Опора на собственные инструменты/рантаймы
- VoiceBot: охват диалогов, summary/роли, ассистент «во время» встречи

## Слайд 13 — AgentFab: SSoT
- Диаграмма разработана и переработана
- План: машинно-читаемый вид + генерация цепочек/промтов/агентов
- SSoT: изменение диаграммы = изменение системы

## Слайд 14 — Стратегсессия (ЕКБ)
- Модели монетизации: агенты/артефакты/наем
- Быстрые победы: трафик, недвижимость, кейсы
- Strato.Space Prompt Framework признан наиболее полным (по оценке ИИ)

## Слайд 15 — Deep Research
- Нужны дип-ресерчи длинных документов и реестров
- Ограничения учеток; как подключить reasoning-модели

## Слайд 16 — Telegram и вызов агентов
- Вызов изготовления агента прямо из чата (текст/голос/транскрипт)
- MCP-call как единый интерфейс вызова
- Две оркестрации: sequence (Mermaid/land-graph) vs LLM-делегация

## Слайд 17 — VoiceBot и UX-среда
- Освоение API: сессии/контекст/выгрузки/компактизация
- Передача в LangChain/MCP (оба пути пригодятся)
- Нужен фронтенд для UX researcher/designer

## Слайд 18 — Временный фронт (PRO)
- Одна PRO-учетка + VPN + единый браузер
- Подключаем MCP без раскрытия промтов (граница — MCP-call)
- Экономика: ~$200 за немедленный фронт, дип-ресерч без лимитов

## Слайд 19 — Потенциал ускорения
- Сшивка фронта и бэка через PRO
- Больше точек интеграции с Telegram
- Открытие VoiceBot: мультисессии, чанки, username; расширения с единой авторизацией

## Слайд 20 — Организационные сдвиги
